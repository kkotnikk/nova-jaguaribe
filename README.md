# Padaria Nova Jaguaribe

Site institucional responsivo da Padaria Nova Jaguaribe, no Brás, São Paulo.

## Conteúdo

- Abertura interativa com manhã, tarde e noite.
- Lista de sabores expansível.
- História da padaria, pedidos, endereço e horários.
- Links de WhatsApp, telefone, Instagram e localização.
- Logo digitalizada em alta resolução e versões sem fundo para o site e ícone da guia.

## Uso

Site estático, sem instalação ou etapa de compilação. Abra `index.html` para visualizar.

Para hospedar no GitHub Pages, selecione a branch `main` e a pasta `/ (root)` em **Settings → Pages**.

As fotografias de comida são ilustrativas. Sabores, valores e disponibilidade devem ser consultados com a equipe da padaria.
